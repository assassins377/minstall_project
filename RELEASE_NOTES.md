## Изменения в v2.2.1

- Исправлен запуск установщиков из путей с пробелами и в кавычках. Код 1641 обрабатывается как успешная установка с перезагрузкой.
- В EXE и Python-пакет включены переводы, профили и иконки; кеш извлечённых иконок вынесен в пользовательский каталог.
- Для автообновления обязательна корректная SHA-256. Отсутствующая, некорректная или несовпадающая сумма блокирует замену EXE.
- Watchdog сообщает о длительной низкой CPU-активности, сохраняя работающий установщик. Явный тайм-аут и отмена пользователем продолжают останавливать процесс.
- README и BUILD уточняют выбор x86/x64, portable ZIP, проверку SHA-256, SmartScreen и ограничения поддержки Windows.

## Проверки и ограничения

Перед публикацией Release workflow запускает Windows-тесты и собирает EXE и portable ZIP для x86/x64. Контрольные суммы публикуются рядом с файлами.

Ручная проверка GUI, реальной установки, отмены и полного цикла самообновления на Windows для этой версии не выполнена. Автоматические тесты используют имитацию процессов и сети и не заменяют такую проверку. Целевая платформа — Windows 10/11; поддержка Windows 7 не подтверждена.
